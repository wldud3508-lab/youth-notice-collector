## 단계 정의
- **실제 연결 성공**: 실제 출처에서 자동으로 받아 성공한 기록이 있음. 시험용 CSV 실행은 해당하지 않는다.
- **준비 완료**: 수집 코드가 있고 시험까지 가능. 인증키·활용신청 같은 설정만 남음.
- **허가 확인 중**: 기술적으로는 받을 수 있으나 이용 범위나 사이트 식별을 확인하는 중. 확인 전에는 켜지 않는다.
- **미연결**: 공식 데이터 제공을 확인하지 못했고 허락도 없음. 내부 API·화면 수집으로 우회하지 않는다.

## 한국장학재단 설계
- 월간 파일이라 '오늘 신규 공고'로 세지 않고 실행 요약에 "정기 자료 반영"으로 따로 표시. 공고마다 원본 기준일(`source_version`)과 우리 수집일을 따로 기록.
- 같은 장학금 식별: 정규화한 (운영기관명, 상품명, 모집시작일). `번호` 열은 파일마다 바뀌어 쓰지 않음. 다음 회차(모집시작일이 다름)는 별개 공고.
- 상품구분 `학자금`(대출·이자지원)은 지원방식으로 분리: 이자지원 / 대출 / 기타(판단 불가 시 참고사항). 장학금은 무상지원.
- 원본에 게시일 열이 없어 `posted_at`은 비워 둔다(파일 기준일과 다름). 행마다 상세 페이지가 없어 출처 링크는 데이터셋 페이지, 기관 홈페이지는 `official_url`.
